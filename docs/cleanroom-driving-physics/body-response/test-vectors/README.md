# Synthetic body-response vectors

Every input is invented; expected outputs are mathematical evaluations of this amendment using static-inferred equations. None was captured by running the original. The private analyst generator uses ordinary arithmetic and binary32 conversion for decimal constants; it executes no original instructions and is not implementation code or an original oracle. Do not ship or consult the private generator when implementing.

The public JSON is the approved handoff material after reviewer gating. `B_columns` lists the three world-space body axes in forward/lateral/up order. The publication vector includes the unrepaired candidate axes separately from the final repaired axes; its expected Omega belongs to the pre-repair publication. Partial-operation vectors enter exactly the named component boundary. Their independent w/L, frame snapshots or other supplied scalars need not form a whole-car state. For example, damping fixtures hold w as a component input, not a stock car trajectory. In the two-substep latency fixture, identical force/moment is supplied again during each preparation; there is no claim the tyre solver generates that exact constant force.

Compare strict gates, selected modes and replacement choices exactly. Compare finite arithmetic components with absolute error <=2e-5 plus relative error <=2e-6 times absolute expected value. Orientation norm/dot residuals may be <=2e-6. These tolerances address binary32 and intermediate precision, not alternative integration schemes or changed application order. Exact zeros in strict predicate inputs are exact fixtures. Decimal threshold inputs already contain their binary32 expansion where required.

Vector groups cover selector transition asymmetry, tilted world-axis momentum adjustment, curve and stabilization gate independence, curve interpolation/clamping, zero/nonzero limit selection, slip/speed strict boundaries, raw-torque replacement after damping, Euler/publication/repair ordering, angular cap without momentum rewrite, forward-anchored orientation repair, force-versus-impulse moment sources, per-application caps and post-cap angular scaling, late opposing torque gates, and force/momentum/pose latency. Host feedback acceptance remains the explicitly required Stage5 composition check in BR-7; these component vectors do not measure retail handling.

Reviewer-added cases cover basic-inertia initialization while adjusted mode is held, tilted inertia publication, braking pitch and lateral roll signs, zero angular impulse scale, exact cap boundaries, state2 selector zero, exceptional state1 gates, remaining damping knots, and force-response/save/clear/gravity publication. Each vector carries its own provenance field; all are independently evaluated specification arithmetic. A component fixture can use h=.1 to expose latency even though ordinary frame subdivision uses smaller substeps; this does not change the ordinary timestep contract.

The candidate-basis alignment vector enters the composed BR-4 interior boundary, where Euler axes have not yet been repaired. Its lateral axis is intentionally not unit length; the cross-product formula yields 1.04, whereas applying the unit-axis-only simplification would incorrectly yield .96.
