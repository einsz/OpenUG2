# Archived temporary 350Z configuration research

This directory is a historical record of the former temporary modified 350Z
experiment. The experiment has been removed from the game, build, tests and
current usage documentation. Commands, paths and results in these records refer
to the former implementation and are not current run instructions.

Reviewed specifications, vectors, provenance and verification records are
preserved unchanged to retain their approved hashes and historical context.
The ordinary stock 350Z remains available through `--car 350Z --drivetrain`;
see [the current drivetrain guide](../../DRIVETRAIN.md).
