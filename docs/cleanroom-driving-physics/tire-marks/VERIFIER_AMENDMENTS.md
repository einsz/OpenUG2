# Tire marks - proposed spec amendments / questions (verifier, 2026-10-16)
Against SPEC.md sha256 99b70795... Each item is for reviewer gating; none is a code instruction.

- V1 (TM-7 step 5, answers TM-IQ1). Proposed statement: "The continuation seed re-encoded through TM-6 equals the old strip's stored point for every byte value; implementations may copy or re-encode." Provenance: verifier exhaustive check of all 256 Ib values, trunc(255*(Ib*b32(1/255))) == Ib in binary32 and double. Vector: Ib in {76, 85, 255, 0} seed round trip unchanged. The implementer's "76->75" claim was not reproduced; ask implementer for the arithmetic path that produced it.
- V2 (TM-12 / TM-2). Proposed statement: published u is forced to 0 for all wheels (and the mean) while the special mover mode is active. Current implementation does not do this; unobservable today (no consumer). Vector needed: alternate_movement=1 -> u=0 on published outputs. Question for analyst: is this required for the mark system or only for the unknown TM-U1 consumers?
- V3 (TM-2 gate). Proposed clarification: state whether G may also be false for (a) contact model not ready, (b) suspended session, (c) frozen/static host states. Implementation uses these; spec lists only effects-enabled, alternate mover, game-state code. Ask: should such host states end open trails (as for a destroyed wheel) or leave them open (spec G-false rule)? Currently left open, then bridged by TM-8/4 m rules on resume.
- V4 (TM-10.2 / TM-IQ5). Proposed testable statement: the 300-frame cell-touch window counts fixed 60 Hz world ticks, not rendered frames. Implementation increments once per main-loop pass; verifier could not confirm that is a 60 Hz tick. Needs a vector with two tick rates, or the spec should say "wall time 5 s".
- V5 (TM-4 step 5). Clarify the ground query: probe z is wheel-centre height; state the acceptable search window above/below (TM-U7). Implementation probes from wheel-centre minus radius with the Stage5 reach limits, which is a different window and determines when a probe "finds no ground".
- V6 (TM-1.2 / TM-IQ7). Add a testable mapping requirement from the Stage5 surface source (material -> id 0..28) so dirt/grass/puddle marks can occur in play. Currently only id 1 is produced by the host; spec parity for k_s=1.4 and puddle forcing is test-only.
- V7 (TM-9 / TM-U5). Add a vector or statement for vehicle reset/car switch: current behaviour does not end the trail; an old strip may chain to a new position only if within 4 m of origin and kappa <= .2, otherwise it ends. Reviewer to decide whether reset must end trails.
- V8 (TM-3 arithmetic). State precision for u computation (binary32 vs double); implementation computes M/Fmax in double and rounds, affecting only exact-tie cases around u*N == 8.
- V9 (TM-11.2 / TM-U4). Spec leaves vertex RGB 128 effect and alpha unity unresolved; implementation ignores vertex RGB and scales alpha x2. Needs TM-Q4 screenshot or original-render reference to close.
