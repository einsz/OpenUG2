Generated by an analyst-only generator written for this project that encodes the statements of
`../SPEC_GUI.md`; it is not code from the original program. Except for `tvg01`, every vector is
**synthetic** (assumed inputs, expected outputs computed from the SPEC rules). None contains retail
package, texture, font or text payload.
