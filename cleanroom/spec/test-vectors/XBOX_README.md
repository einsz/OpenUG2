# Xbox synthetic vector provenance

`xbox_controller_vectors.json`: freshly generated artificial BC2 red/alpha ramp and BC1 transparent blocks. RGBA expectations are calculated from standard BC1/BC2 format rules restated in XBOX_CONTROLLER, and contain no original pixels. Invalid extents/descriptor-shape cases are artificial bounds tests. The 49×124/49×60 shape follows observed controller-pack structure.

`xdvdfs_vectors.json`: freshly generated directory entry for invented filename TEST and expected sector/file offsets, plus invalid name/child bounds. Source format: https://multimedia.cx/xdvdfs.html. Generated by analyst-owned `analysis/scripts/xbox_controller_vectors.py`, which is not implementation input.
